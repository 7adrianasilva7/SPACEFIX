# SPACEFIX - PFA - GD1

## Version UE5.7.4

Projet de fin d'année - Ecole Brassart - Réalisé en 1 mois

Description :
Le cargo spatial de SPACEFIX transporte trois satellites essentiels au rétablissement d'un réseau de communication mondial. Vous êtes l'unique technicien à bord. 
La mission est simple : charger chaque satellite sur le rail magnétique, l'escorter jusqu'au cockpit et valider le déploiement. 
Mais FALCO, la société rivale, envoie ses agents à l'intérieur du vaisseau pour faire échouer l'opération. Vous devez donc neutraliser toute tentative d'interérence ou de sabotage liée à FALCO

Contrôles : Manettes;
- Tirer : LT
- Réparer : RT
- Equiper : Y
- Déplacement : Joystick gauche
- Caméra : Joystick droit
- Pause : Bouton menu
- Interagir : A

Moteur : Unreal Engine

Assets utilisés : FAB et Sketchfab

SFX utilisés : Freesound - Pixabay 

Game Designer : Téva FERREIRA / Adriana Massebeuf / Titouan Bertrand-levrel
